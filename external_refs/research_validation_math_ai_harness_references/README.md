# 技術調査・検証・数理・AIハーネス公開調査

調査日: 2026-09-08

## 目的

技術調査、技術検証、数理検証、AI評価を再現可能にするため、公式文書と主要OSSから確認できた事実を整理する。

## 公開範囲

このディレクトリに置くもの:

- 公開sourceのURL、運営主体、用途。
- 公式資料から確認できた仕組み。
- 導入前に再確認すべき制約。
- 4領域に共通する公開可能な設計原則。

このディレクトリに置かないもの:

- 熟練者の判断手順、暗黙知、チェックシート。
- 内部profile、対象path、しきい値、waiver条件。
- ローカルrepository名、内部構成、検出結果。
- 実行権限、credential、攻撃入力。

非公開部分はgitignore対象のskillで管理する。

## 読む順番

1. [分野別カバレッジ](coverage-matrix.md): 何を調べ、何が未調査か。
2. [source catalog](source-catalog.md): 公式資料、一次論文、主要OSSの用途と限界。
3. [調査結果](research-findings.md): 4領域の共通点と、領域ごとに異なる判断対象。
4. [研究から実用化への引き渡し](research-to-production-handoff.md): 別領域の評価を混ぜずにつなぐ契約。

## 調査の完了条件

source数ではなく、次を満たした時点を公開調査の一区切りとする。

- 重要な各分類に、少なくとも1つの標準、公式文書、または一次論文がある。
- 主要な判断項目について、確認できることと確認できないことが分かれている。
- 研究、再現、実用化、運用の合流条件が定義されている。
- tool名ではなく、検証目的から必要な手法を選べる。
- 未調査または対象固有で追加調査が必要な部分が明示されている。

## 現時点の範囲

- 分類別の公開調査: 一区切り。対象案件ごとの追加調査は必要。
- 研究開発と実用化の引き渡し設計: 公開可能な共通部分を作成済み。
- 非公開skillとチェックシート: ローカル管理。
- toolの導入、実測比較、Go adapter実装: 未実施。

tool名が掲載されていても、導入推奨の確定ではない。version、license、外部送信、権限、再現性、結果形式を対象環境で再確認する。
