# 公開セキュリティハーネス参照

調査日: 2026-09-08

## 目的

公開GitHubリポジトリと公式文書から、セキュリティ確認に再利用できる事実、ツール候補、導入時の注意を集める。

このディレクトリには公開情報だけを置く。非公開ハーネスの内部構造、対象path、しきい値、例外、実行結果は置かない。

## 読む順番

1. [調査元一覧](source-catalog.md): URL、確認できた事実、採用できる考え方、限界。
2. 非公開skill: 熟練者の判断手順、暗黙知、チェックID、優先順位、ツール連携を管理する。公開repositoryには含めない。

## 公開・非公開の境界

- 公開: URL、公開仕様から確認できた事実、license確認状況、一般的な導入注意。
- 非公開: 熟練者の判断順、適用条件、優先順位、しきい値、チェックシート、ローカルrepositoryから得た知見。
- 実行結果: secret、内部host、個人情報を除去し、公開可否を別途判定する。

## 調査時点の制約

- GitHub repository metadataとNyx Foundation主要READMEを確認した。
- 一部repositoryは、調査中の一時的なGitHub raw content取得失敗により、README全文ではなくrepository metadataと公開説明までを確認した。
- 各toolのCLI option、現行version、license例外は、導入時に公式文書を再確認する。
- 今回はtoolのinstall、実行、精度比較を行っていない。

## 更新ルール

sourceを追加するときは、URLだけでなく次を記録する。

- 確認日。
- 運営組織とlicense。
- 実際に確認できた機能。
- どの調査領域へ関係するか。
- tool単体では確認できないこと。
- 導入前に必要な追加確認。
