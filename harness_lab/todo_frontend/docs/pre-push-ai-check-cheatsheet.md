# pre-push/PR AIチェックチートシート

## 1. 目的

push や PR の前に、AIへ渡す短い確認表。

`pre-push-ai-concept-gate.md` はゲート仕様。このファイルは、AIが実際にチェックする時の読み方です。

## 2. 使うタイミング

- push前。
- PR作成前。
- PR説明やIssueコメントを書く前。
- AIが `OKです` と言う前。

## 3. 入力として渡すもの

| 入力 | 必須 | 使い方 |
|---|---|---|
| ユーザー依頼 | 必須 | 何を求められたかを見る |
| `git diff` | 必須 | 何を変えたかを見る |
| 関連ルール | 必須 | README、AGENTS、該当docsと矛盾しないか見る |
| 実行結果 | ある場合 | 機械checkのOK/NGを見る |
| 未解決点 | ある場合 | push/PRを止めるものか分ける |

## 4. 最初に分けるもの

| 種類 | 例 | 扱い |
|---|---|---|
| 人間の観察 | `UIの必要性説明が足りない気がする` | 観察メモとして残す |
| 人間の語感/違和感 | `なんか混ざっている` | 直接Harness対象にしない |
| AIの解釈 | `必要性チェックが不足しているのでは` | 推測として扱う |
| 機械判定条件 | `各UIに目的/効果/完了条件があるか` | Harness対象にできる |
| 未確定 | `どの粒度で見るか未定` | OK扱いにせず、確認または保留する |

## 5. 見る順番

1. 今回の対象を1文で言う。
2. ユーザーの原文と、AIの解釈がズレていないか見る。
3. 人間の違和感と、機械判定条件が混ざっていないか見る。
4. Harness化するなら、判定条件へ変換できているか見る。
5. 実行結果がある場合は、結果と判断が対応しているか見る。
6. `OK / NG / USER_CONFIRM` を決める。

## 6. NG条件

- 人間の語感や違和感を、Harnessが直接検出したように書いている。
- 観察メモを、判定条件へ変換せずにcheck項目へ入れている。
- ユーザー原文をAIの解釈で変えている。
- 対象外のスコープへ勝手に広げている。
- `OK` の根拠が、雰囲気や一般論になっている。
- NGなのに、pushやPRへ進もうとしている。

## 7. OK条件

- ユーザー依頼、差分、関連docsを見たと言える。
- 観察、違和感、解釈、機械判定が分かれている。
- Harness化するものは、機械で見られる条件になっている。
- 残リスクがある場合も、push/PRを止めるものか分けている。
- 次に何をするかが明確。

## 8. 出力フォーマット

```text
AI gate result: OK / NG / USER_CONFIRM

対象:
- <今回の差分>

見たもの:
- <ユーザー依頼>
- <git diff>
- <関連docs>
- <実行結果>

概念境界:
- <混ざっていない / 混ざっている>

Harness化:
- <判定条件へ変換済み / 未変換 / 対象外>

判断:
- <なぜOK/NG/確認か>

次の行動:
- <push/PRへ進む / 修正する / ユーザーに確認する>
```

## 9. 具体例

NG:

```text
人間の違和感5件のうちHarnessで拾えたのは1件だった。
```

理由:

- 人間の違和感を、Harnessが直接検出できるものとして扱っている。
- 概念空間が混ざっている。

OK:

```text
ユーザーは `UIコンポーネントごとの必要性説明不足` に違和感を持った。
これはHarnessが直接拾う対象ではない。
Harness化するなら、`各UIコンポーネントに目的、利用者への効果、必要性、完了条件が書かれているか` を判定条件にする。
```

理由:

- 人間の違和感と機械判定条件を分けている。
- Harness化する場合の変換先がある。

## 10. AIへ渡す最小プロンプト

```text
次のユーザー依頼、git diff、関連docs、実行結果を見て、push/PR前AIチェックをしてください。

見る観点:
- 人間の違和感と機械判定条件を混ぜていないか
- ユーザー原文をAIの解釈で変えていないか
- Harness化するものは判定条件へ変換されているか
- NGならpush/PRへ進めず、修正対象を出す

出力は次の形:
AI gate result: OK / NG / USER_CONFIRM
対象:
見たもの:
概念境界:
Harness化:
判断:
次の行動:
```
