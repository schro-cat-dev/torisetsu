# はじめに

このリポジトリは、ハーネスを組むための実験的な作業情報を格納するためのリポジトリである。

- AIはどういう挙動をするのか、どういう入力に対してどのようなアウトプットを出すのか

- どういう制約や入力を与えればどのくらいの精度で動くのか、アウトプット目標とするチェックリストをどこまで満たすのか

- AI内部のアーキテクチャを分解するとどうなっているのか

などの項目を実際に調査実験するためのものである。

内容に関しては本 README も含め、適宜更新していく予定である。

## リポジトリの管理ルール

- このリポジトリは実験場であり、システム的な開発の用途ではないため、初期フェーズにおいては、main ブランチ以外のブランチは使用せずに管理する

- 1つ上に記載項目について、もしシステムを模擬的に開発し、連携する場合においては、ブランチをそのシステム名で作成し、そこから派生してmainベースで管理するものとする（システムとしてのデプロイ・公開はソースコードおよび運用のセキュリティ上許容しないため、個別のmain相当ブランチに対してdevelop, stagingともに用意しない）
