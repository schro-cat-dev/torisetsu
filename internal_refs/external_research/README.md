# 外部調査

## 目的

外部公開資料から確認した内容を、既存の会話メモ、AI協働ナレッジ、個別実験ログと混ぜずに保管する。

## ディレクトリ

| ディレクトリ | 役割 |
|---|---|
| `ui_design_harness_foundation/` | UIデザインの土台ルールとハーネス化候補の外部調査 |
| `speakerdeck_design_harness_2026/` | SpeakerDeck資料「デザインハーネス」の情報抽出と採用時の補正メモ |

## 分離ルール

- 外部資料から確認できる事実と、AIの解釈を分ける。
- 既存設計へ反映する場合は、反映先、変更理由、残リスクを別途記録する。
- 外部資料の全文転載やOCR全文保存はしない。要点、出典、抽出方法、確認日を残す。
