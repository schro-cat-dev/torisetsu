# UIデザインハーネス基礎調査

## 目的

UIデザインの土台ルールを、外部公開ドキュメントから独立して調査する。

このディレクトリは、これまでの会話メモ、AI協働ナレッジ、既存ハーネス設計とは混ぜない。ここに置く内容は、外部資料から確認できる事実と、その事実から作れるハーネス候補を分けて記録する。

## 分離ルール

- 既存の `internal_refs/ai_experiment_scopes/` へ直接追記しない。
- 既存の `internal_refs/core_concepts/` へ直接追記しない。
- この調査結果を既存設計へ反映する場合は、別タスクとして反映先、反映内容、変更理由を明示する。
- 外部資料の内容、AIの解釈、ハーネス化候補を混ぜない。
