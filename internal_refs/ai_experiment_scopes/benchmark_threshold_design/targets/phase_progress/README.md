# Phase進捗ベンチマーク

## 目的

Phase 1で、同じ流れを繰り返した時にズレが減っているかを見る。

## 指標

| 指標 | 意味 | 見方 |
|---|---|---|
| 仕様差分 | 期待仕様と成果物のズレの数 | 少ないほどよい |
| Harness検出 | ハーネスが自動で見つけたズレの数 | 総数だけでなく比率を見る |
| 人間検出 | 人間レビューで初めて見つかったズレの数 | 少ないほどよい |
| 修正依頼 | ユーザーが修正を依頼した回数 | 少ないほどよい |

## 初期例

| 指標 | 初回 | 改善後 | 読み方 |
|---|---:|---:|---|
| 仕様差分 | 18 | 6 | 差分総量が減っている |
| Harness検出 | 9 | 5 | 数は減るが、検出比率は上がっている |
| 人間検出 | 9 | 1 | 人間だけが見つけるズレが減っている |
| 修正依頼 | 7 | 2 | 手戻りが減っている |

## 暫定閾値

| 指標 | 条件 | 初期値 | 単位 |
|---|---|---:|---|
| 仕様差分の減少率 | `>=` | 50 | % |
| 人間だけが見つけるズレの減少率 | `>=` | 70 | % |
| 修正依頼回数の減少率 | `>=` | 50 | % |
| Harness検出比率 | `>=` | 70 | % |

この閾値は仮です。実測3回未満では、合否ではなく観察目安として扱う。
