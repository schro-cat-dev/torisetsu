# プロンプト品質ベンチマーク

## 目的

プロンプトが、AIの作業品質やズレの少なさに効いているかを見る。

## 見る対象

| 領域 | 見ること |
|---|---|
| 目的 | 何をするかが明確か |
| 制約 | してよいこと、しないことが明確か |
| 出力形式 | 期待する形が明確か |
| 評価軸 | 良し悪しの見方が明確か |
| 具体例 | 粒度が伝わる例があるか |
| 期限 | 作業の重さを調整できるか |

## 初期指標

| 指標 | 意味 |
|---|---|
| 指示漏れ数 | AIが解釈で補った箇所 |
| 修正依頼回数 | ユーザーが出した修正回数 |
| 出力形式ズレ | 指定形式と違った数 |
| 余計な作業数 | 事前確認なしに増えた作業 |
| 有効な提案数 | ユーザーの観点外から役に立った提案 |
