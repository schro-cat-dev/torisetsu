# ハーネス品質ベンチマーク

## 目的

ハーネスが本当に品質を測れているかを見る。

## 見る対象

| 領域 | 見ること |
|---|---|
| 検出力 | 仕様差分や不具合を見つけられるか |
| 誤検出 | 問題ではないものを落としていないか |
| 証跡 | summary、result JSON、コマンドが残るか |
| 再現性 | 同じ入力で同じ結果になるか |
| 責務分離 | runner、policy、scenario、contractが分かれているか |

## 初期指標

| 指標 | 意味 |
|---|---|
| Harness検出比率 | Harness検出数 / 仕様差分数 |
| 人間のみ検出比率 | 人間検出数 / 仕様差分数 |
| 実行時間 | check完了までの時間 |
| 証跡不足数 | 結果が後で追えない項目 |
