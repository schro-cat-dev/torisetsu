# TODOアプリレビューベンチマーク

## 目的

簡易TODOアプリをレビューし、ハーネスとプロンプトの抜け漏れを見つける。

## 見る対象

| 領域 | 見ること |
|---|---|
| UI | 表示、状態、操作、エラー、空状態 |
| API | contract、CRUD、失敗時、保存との整合 |
| 保存 | local JSON、復元、テスト後のrestore |
| UX | 入力、検索、絞り込み、スマホ、文言 |
| a11y | label、keyboard、axe、色以外の状態伝達 |
| テスト | unit、API flow、E2E、静的check |

## 初期指標

| 指標 | 意味 |
|---|---|
| レビュー観点数 | 何項目を見たか |
| 不足数 | 見つかった不足 |
| 自動検出済み数 | ハーネスが拾えた不足 |
| 人間レビューのみ数 | 人間が初めて見つけた不足 |
| 次回ハーネス化候補数 | 自動化できそうな不足 |
