# 対象別ベンチマーク

## 目的

ベンチマークは対象ごとに違うため、ここで責務を分ける。

## 対象

| 対象 | ディレクトリ | 主に見ること |
|---|---|---|
| Phase進捗 | `phase_progress/` | ズレと修正依頼が減っているか |
| TODOアプリレビュー | `todo_app_review/` | UI、API、保存、UX、a11y、テストの不足 |
| ハーネス品質 | `harness_quality/` | 自動検出できる範囲と残る人間確認 |
| ハーネス改善効果 | `harness_effectiveness/` | Harness改善で修正回数、時間、品質通過率が改善したか |
| プロンプト品質 | `prompt_quality/` | 指示の粒度、制約、評価軸、出力形式 |

## 追加ルール

- 1つの対象に、複数の評価軸があってよい。
- 異なる対象の閾値を混ぜない。
- 数値だけでなく、なぜその指標を見るかも書く。
