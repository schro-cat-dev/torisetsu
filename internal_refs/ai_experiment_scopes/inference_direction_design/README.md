# 推論の方向づけ

## 目的

プロンプトでAIの推論をどの方向に向けるかを整理する。

ここでの `ベクトルづけ` は、数学的な内部ベクトルを直接見るという意味ではない。入力でどの観点を強め、どの観点を弱めるかを管理するための言い方として扱う。

## 方向づけの要素

| 要素 | 何を決めるか | 例 |
|---|---|---|
| 目的 | 何を達成するか | 後で比較できる実験ログを作る |
| 優先順位 | 何を先に見るか | 再現性を最優先 |
| 制約 | 何をしないか | READMEを勝手に大きく書き換えない |
| 出力形式 | どう出すか | 表、箇条書き、JSON |
| 評価軸 | 何で良し悪しを見るか | 修正回数、漏れ、時間 |
| 具体例 | 期待する粒度 | `AがBを呼ぶ / BはAの価値で成立する` |

## 具体例

```text
方向づけ:
- 目的: READMEの思想を薄めず、読みやすくする
- 優先順位: ノイズ削減 5 / 情報保持 4
- 制約: 強い言葉を避ける
- 出力形式: 3軸の箇条書き
```
