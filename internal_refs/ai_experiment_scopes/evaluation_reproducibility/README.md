# 評価と再現性

## 目的

AIの出力を、印象だけでなく比較できる形にする。

## 評価軸

| 評価軸 | 見るもの | 例 |
|---|---|---|
| 正確性 | 事実・ファイル・コマンドが合っているか | 存在しないファイルを挙げていない |
| 完了度 | 依頼をどこまで満たしたか | docs作成、ログ追記、push完了 |
| ノイズ量 | 不要な説明が多くないか | 直接関係ない一般論が多い |
| 再現性 | 同じ入力で近い結果になるか | 同じpromptで2回試す |
| 修正コスト | 人間が直す量 | 修正依頼回数、修正行数 |
| 時間コスト | 完了までの時間 | 5分、20分、1時間 |

## 記録例

```text
実験ID:
期待:
結果:
修正回数:
人間レビュー時間:
OK/NG:
残リスク:
```

## 注意

- AIが `できました` と言っても、実行結果や差分を見て確認する。
- 1回だけの結果で断定しない。
- 比較する場合は、prompt以外の条件をできるだけそろえる。
