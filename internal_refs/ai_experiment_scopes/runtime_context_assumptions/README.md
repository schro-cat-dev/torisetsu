# 実行時条件の推測

## 目的

モデルの内部学習セット、割当リソース、動作パラメータなどは直接見えないため、観測可能なメタ情報と推測を分けて記録する。

## 扱うこと

| 種類 | 扱い |
|---|---|
| モデル名、日付、環境 | 可能なら事実として記録する |
| tool権限、sandbox、ネットワーク | 実行条件として記録する |
| 内部学習セット | 原則として直接断定しない |
| 割当リソース | レイテンシ、失敗、再試行などから推測に留める |
| 動作パラメータ | 明示されている場合だけ記録し、不明なら不明とする |

## 記録テンプレート

```text
実行日:
モデル/環境:
使えたtool:
ネットワーク:
ファイル権限:
観測できた挙動:
推測:
推測の強さ:
未確認:
```

## 具体例

```text
観測: 同じ依頼でも、追加制約があると出力が短くなった。
推測: モデル内部が変わったのではなく、プロンプト上の優先順位が変わった可能性が高い。
未確認: 実際の推論パラメータや割当リソースは不明。
```
