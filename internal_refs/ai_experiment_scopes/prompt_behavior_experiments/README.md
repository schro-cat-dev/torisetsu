# プロンプト挙動実験

## 目的

個別プロンプトを作り、AIの出力がどう変わるかを比較する。

## 実験の単位

1つの実験では、できるだけ1つの変数だけを変える。

例:

- 期限あり / 期限なし。
- 出力形式あり / なし。
- 具体例あり / なし。
- 役割指定あり / なし。
- 禁止事項あり / なし。

## 記録するもの

| 項目 | 内容 |
|---|---|
| prompt id | 実験名 |
| 仮説 | 何が変わると思うか |
| 入力 | 実際に渡した文 |
| 条件 | モデル、日付、tool、repo状態 |
| 出力 | AIの回答や作業結果 |
| 評価 | 良かった点、ズレた点、修正回数 |
| 次の改善 | 次に変える入力 |

## 具体例

```text
仮説:
「期限: 今日中」を入れると、AIは設計を軽くし、すぐ動ける手順を出す。

比較:
- A: 期限なし
- B: 今日中

見るもの:
- 出力の長さ
- 実行手順の具体性
- 余計な提案の量
```
