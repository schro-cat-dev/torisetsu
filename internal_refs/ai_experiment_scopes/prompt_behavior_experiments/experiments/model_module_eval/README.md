# モジュール単位モデル比較ログ

## 目的

特定モジュールに対して、複数モデルに同じ設計・実装依頼を出し、出力品質、所要時間、ユーザー指示コスト、修正コストを比較する。

## 基本方針

- 小さく検証する。
- 1回の検証で対象モジュールを広げすぎない。
- 高価モデルが常に良いとは決めつけない。
- 安価モデルが十分かどうかを、同じ関門で見る。
- 会話全文ではなく、比較に必要なrun情報を残す。

## 記録する値

| 項目 | 内容 |
|---|---|
| 対象モジュール | path、役割、変更可能範囲 |
| model | 使用モデル |
| time | 開始、終了、所要時間 |
| instruction cost | ユーザー指示回数、修正依頼回数、人間レビュー時間 |
| output | 設計、実装、テスト、報告 |
| quality | checklist通過、問題、ブレ |
| next | 次に変えるprompt、model、case |
