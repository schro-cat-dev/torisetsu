# AI協働ナレッジ

## 目的

AIが業務ドメイン、大枠の技術指針、観点ごとのフレームワーク設計、トレードオフ判断で迷った時に、ユーザーから返った判断や補正を蓄積する場所です。

## 保存するもの

- AIが品質を担保しきれず、ユーザーへボールをパスした場面。
- ユーザーが返した判断、補正、具体例、方針。
- 次回同じ場面でAIがどう動くか。

## 保存形式

```text
日付:

状況:

AIが迷った点:

ユーザーの返答:

次回の動き:
```

## 注意

- 会話全文は `internal_refs/chat_logs/` に置く。
- ここには、次回の判断に使える短いナレッジだけを置く。
- ユーザーの原文が必要な場合は、短く引用し、解釈と混ぜない。
