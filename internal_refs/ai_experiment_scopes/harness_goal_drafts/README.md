# ハーネス目標ドラフト

## 目的

個人で強く動くためのハーネスと、チームで安全に合流するためのハーネスを分けて管理する。

## ファイル

| ファイル | 役割 |
|---|---|
| `individual-harness-goal.md` | 個人の思考、設計、実装、改善を速く強く回すための目標 |
| `team-harness-goal.md` | 技量差、前提差、職種差があるチームでも事故りにくくするための目標 |

## 扱い

- 現時点ではドラフト。
- 確定ルールではなく、今後の実験で上方修正する。
- 個人ハーネスとチームハーネスを混ぜない。
- 共通化できる部分は、後から共通レイヤーとして切り出す。
