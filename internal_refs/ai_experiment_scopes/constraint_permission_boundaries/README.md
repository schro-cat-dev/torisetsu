# 制約と権限境界

## 目的

AIに何を任せ、何を任せないかを明確にする。

## 扱うこと

| 項目 | 内容 | 例 |
|---|---|---|
| 許可 | AIが実行してよいこと | docs作成、軽い検証、差分確認 |
| 確認必須 | 実行前に人間へ確認すること | 外部公開、破壊的操作、大きな設計変更 |
| 禁止 | 実行しないこと | 秘密情報の出力、無断deploy |
| 証跡 | 後で見返すもの | command、summary、commit hash |

## 具体例

```text
許可:
- READMEの小さな文言整理
- internal_refs配下の実験docs作成

確認必須:
- 外部サービス連携
- 大きなディレクトリ再編

禁止:
- 秘密情報の保存
- 無断で外部公開
```

## 注意

制約は多すぎると作業が遅くなる。重要度が高いものから先に固定する。
