# TODO UI判断証跡

- 主目的: TODOを追加し、検索・詳細確認・編集・完了・削除まで行う。
- 画面構成: 一覧を土台にし、新規作成と編集はdialog、詳細は対象行の直下へ出す。
- 操作阻害: 保存条件を満たさない間だけsubmitをdisabledにし、キャンセルと再試行を残す。
- 表示文言: 状態、優先度、分類、期限を利用者向け日本語で表示する。
- 非表示情報: 内部ID、debug情報、harness versionは通常画面に表示しない。
- 採用例: checkboxだけが完了状態を変え、タイトル領域は詳細開閉だけを行う。

判断主体は人かAIかで上下を付けず、同じSchema、必要証跡、合格条件を適用する。
