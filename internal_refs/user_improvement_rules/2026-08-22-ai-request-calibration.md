# 2026-08-22 ai request calibration

## 1. AIに伝わる依頼文へ一緒に直す

- 日付: `2026-08-22`
- 分かったこと: ユーザーは、思った動きと違った時に、依頼文とAI解釈のズレを一緒に見直したい。
- 状況: 背景推測の意味がAIに少しズレて伝わった後の会話中に判明。
- 理由: AIの受け取り方に合わせて指示文を調整できると、やり直しが減るため。
- 次の動き: ズレた時は、`依頼文`、`AIの解釈`、`実際の動き`、`ズレた点`、`ユーザー案`、`AI案`、`次の指示文` に分ける。
- 例: `次回は「まず確認だけして、編集はしないで」と書くと、AIが勝手に作業しにくくなる。`
- 視点: `依頼の伝わりやすさ`
- 優先度: `5`
- おすすめ度: `5`

## 2. ユーザー案とAI案で擦り合わせる

- 日付: `2026-08-22`
- 分かったこと: ユーザーは、ズレた時に自分から案を出しつつ、AI側からも伝わりやすい案を出してほしい。
- 状況: 依頼文とAI解釈のズレをどう扱うか整理している会話中に判明。
- 理由: 双方から案を出すと、次回の依頼文が早く整うため。
- 次の動き: `ユーザー案` と `AI案` を並べて、短く擦り合わせる。
- 例: `ユーザー案: まず確認だけ / AI案: 編集前に確認し、承認後に変更する`
- 視点: `依頼の伝わりやすさ`
- 優先度: `5`
- おすすめ度: `5`
