# Thinking Pattern Check Cheatsheet

認知のズレや歪みがありそうな時に、軽く確認して改善案を出すためのメモ。

## 使う場面

- 話が少し噛み合っていないとき。
- 考え方に変な癖や混ざりがありそうなとき。
- ユーザーが改善したいと言っているとき。
- 別案を出すとき。

## 出し方

- `気になった点`: どこがズレて見えたか。
- `原因の推測`: なぜそうなっていそうか。
- `改善案`: こうしたらよさそう、という次の動き。
- `根拠`: AI目線で、なぜその案がよいか。

## テンプレート

```text
気になった点: <具体例>
原因の推測: <こうではないでしょうか？>
改善案: <こうするとよさそうです>
根拠: <なぜよいか>
違えば直します。
```
