# 派生ドキュメントの関連づけ不足

## ユーザーフィードバック

```text
これ、言われないとしないってことはルールというかタスクに関連づけたすることとしてきちんと設定できてないし、あとはどういう感じでするかについてのさっきの指示も具体的にサンプルとか記載して、再現性持たせるとかもできないよね

再現性持たせるのは同じ詳細の粒度で全く同じような特徴でアウトプットを出すということです
ちょっと厳しいかもだけどできる？
```

## ズレた点

AIは、講評ログを作ること自体は行ったが、起点文書への反映、辿れるリンク、同じ粒度で再現するためのサンプルをタスクの完了条件として最初から扱えていなかった。

## 次回の動き

- 派生ドキュメントを作る依頼では、作成前に起点文書を特定する。
- 完了条件に `起点文書へのリンク`、`反映内容の要約`、`派生文書側の事実 / 講評 / 扱いの分離`、`確認方法` を入れる。
- ルール化する場合は、抽象ルールだけでなくOK例、NG例、完了前チェックを同じ作業で追加する。
- 再現性は、同じ種類の依頼で同じ詳細粒度と同じ特徴のアウトプットが出ることとして扱う。

## 使える文

```text
派生ログを作るので、起点文書にも関連ログへのリンクと反映済み要約を入れます。
完了条件は、起点文書、派生文書、反映内容、辿り方、確認方法が揃っていることです。
```

## ダメな文

```text
ログを作りました。
```

## なぜ使えるか

作成物だけでなく、後から読む人がどこから辿るか、何が反映済みか、次回AIがどの粒度で再現するかまで固定しているため。
