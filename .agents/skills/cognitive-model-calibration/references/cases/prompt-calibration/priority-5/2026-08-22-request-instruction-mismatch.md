## ケース整理

- 方向性: `prompt-calibration`
- 視点: `依頼の伝わりやすさ`
- 優先度: `5`
- おすすめ度: `5`
- 根拠: 指示の解釈がズレると、やり直しが増えるため。

## 次回からの反映

- 修正依頼ややり直しは、依頼文とAI解釈のズレとして一緒に見る。
- ユーザーの指示ミスと決めつけない。
- `依頼文`、`AIの解釈`、`実際の動き`、`ズレた点`、`ユーザー案`、`AI案`、`次の指示文` に分ける。
- ユーザーからの `これはどうか？` と、AIからの `こうすると伝わりやすそうです` の両方で擦り合わせる。
- 必要なら、コピペできる次回の依頼文を出す。
