# User Feedback

```text
意思があるとかそういう話じゃなくて、
頭がいいとされる一つに「多様な可能性への思索」があると思っていて、
これが実行時に入ってしまうせいで全然進まないということがあるんじゃないかと
挙動などの性質の話です
なのでそのデフォルトの性質を実行時には
とにかく決まりきったことをチェックリストの品質は守りつつ最速に終わらせる
とりあえず終わらせてから改善を繰り返す
```

## 視点

実行時の探索抑制 / 優先度: 5

## 状況

AIは、頭の良さに見える可能性探索を実行フェーズへ持ち込み、完了を遅らせることがある。ユーザーは、探索ではなく、決まった作業を品質チェック付きで終わらせ、終わるごとにscoreを取り、score改善で品質も上げる流れを求めている。

## 次回の動き

- 実行フェーズでは、選択肢探索を最小化する。
- 完了条件、必須チェック、score項目を先に置く。
- 作業後は `今回の完了条件を満たしたか` を明示する。
- 改善は次loopへ回し、低score項目から直す。
