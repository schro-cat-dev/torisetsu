# User Feedback

```text
今まで何も指示やプロトコルなど指示せずに依頼してきて
今回はまだ「モデルAPIを呼んで実行する」ところまでは作っていません。そこは次段階で、provider別adapterを足すのが自然です。順番としては、smoke 5件の実ケー
  ス化 → OpenAI/Claude adapter → ACTION/BLOCK時のproposal JSON生成 がよいです。

みたいな返答というか最後の報告をくれるんだけど、
結局毎回
・見積もりができてない
・見積もりに対して本当に終わらせようという気が恐らくさらさらなく品質改善すらしようとしてない
というのがあなたみたいなAIからすごく感じてて、永遠に終わらないってことがたくさんあるんですよね
```

## 視点

タスク完了見積もり / 優先度: 5

## 状況

AIが成果物を作った後、未実装の次段階を自然に提示するが、全体ゴールまでの残距離、見積もり、完了条件、いつ終えるかの握りが弱い。

## AIが迷った点

- 今回のturnで終える範囲と、全体ゴールまでの範囲を分けきれていない。
- 「次にやること」を出しているが、見積もりと完了条件がない。
- 未実装項目を残す場合、なぜ残したか、いつ終わるか、何が必要かが弱い。

## 次回の動き

- 重めの作業では、最初か最後に `今回の完了範囲 / 全体ゴール / 残作業 / 見積もり / blocker / 次に終える単位` を出す。
- `次段階` と言うだけで終えない。各項目に、所要時間、必要入力、完了条件、未実施リスクを添える。
- 終わらせる意思は主張ではなく、実行可能な小さい完了単位、実測、チェック、残距離で示す。
- AGENTSまたはskillに入れるなら、`No Naked Next Steps` ルールとして、次作業を出す時は見積もりと完了条件を必須にする。
