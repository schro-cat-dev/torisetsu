# 小さく検証して断定しすぎない

ユーザーのメッセージ:

```text
小さく検証する
これはたぶん大事（断定しすぎると頭が凝り固まるのとめんどくさい人間になりそうなので避けたい）
```

## 視点

モデル比較、設計比較、プロンプト比較の進め方。

## 優先度

5

## 内容

ユーザーは、モデル性能やプロンプト設計について大きく断定しすぎるより、特定モジュールに対して小さく設計・実装を試し、結果、時間、指示回数、修正回数を蓄積して振り返る進め方を重視している。

## 次回の動き

- 大きな結論を先に固定しない。
- まず1モジュール、1ケース、複数モデルで比較する。
- 所要時間、ユーザー指示回数、修正依頼回数、人間レビュー時間を記録する。
- 全体チャットログとは別に、個別検証ログも残す。
