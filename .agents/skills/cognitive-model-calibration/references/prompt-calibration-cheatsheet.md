# Prompt Calibration Cheatsheet

依頼とAIの動きがズレた時に、次の依頼文へ直すためのメモ。

## 使う場面

- ユーザーが修正依頼ややり直しを出したとき。
- ユーザーが「思った動きと違う」と感じたとき。
- AIが確認不足、深読みしすぎ、作業範囲の取り違えをしたとき。

## 分け方

- `依頼文`: ユーザーが実際に言ったこと。
- `AIの解釈`: AIがどう受け取ったか。
- `実際の動き`: AIが何をしたか。
- `ズレた点`: 期待と違ったところ。
- `ユーザー案`: ユーザーからの「これはどうか？」。
- `AI案`: AIからの「こうすると伝わりやすそうです」。
- `次の指示文`: 次回AIに伝わりやすい書き方。

## テンプレート

```text
ズレた点: <期待と違ったところ>
原因の推測: <AIがこう解釈した可能性>
ユーザー案: <ユーザーから出た修正案>
AI案: <AIからの伝わりやすい書き方>
次の指示文: <コピペできる依頼例>
根拠: <この書き方だとAIが迷いにくい理由>
```
