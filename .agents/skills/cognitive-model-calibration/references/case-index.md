# Cognitive Model Calibration Case Index

## 保存場所

`references/cases/<direction>/priority-<1-5>/YYYY-MM-DD-topic.md`

## 優先度

- 数字は `5` が高く、`1` が低い。
- 優先度は、必ず視点とセットで書く。例: `視点: 初期環境構築 / 優先度: 5`。
- `priority-5`: 次回から必ず反映する。
- `priority-4`: 高頻度で参照する。
- `priority-3`: 状況が近いときに参照する。
- `priority-2`: 参考程度。
- `priority-1`: 保留または低頻度。

## 方向性

- `ratio-calibration`: `事実 / 観察 / 解釈 / 推測` の比率や濃度のズレ。
- `execution-friction`: 考えすぎで実行が遅れる傾向と、すぐ動くための整理方法。
- `priority-scale`: 優先度の視点、数字の向き、おすすめ度表記のズレ。
- `task-weight-calibration`: 依頼の重さ、推論量、確認量のズレ。
