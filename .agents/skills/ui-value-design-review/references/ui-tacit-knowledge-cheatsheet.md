# UI暗黙知チートシート

このファイルは、UI修正やレビューで出た暗黙知を、次回も使える形で残すためのチートシートです。

優先度とおすすめ度は5が高い。

## 1. 使うタイミング

- ユーザーが `違和感がある`、`なんでここにあるの？`、`いらない説ない？` と言った時。
- 画面は動くが、使いやすいか怪しい時。
- UI修正が、別の表示、状態、API、テストへ波及しそうな時。
- skillやdocsに入っているのに、同じ失敗が再発した時。

## 2. 最初に見る観点

| 観点 | 見ること | 例 | 優先度 |
|---|---|---|---:|
| 提供価値 | そのUIで何が楽になるか | 分類バーでTODOを探しやすくする | 5 |
| 対象との近さ | 情報や操作が対象の近くにあるか | 詳細は対象カード内で開く | 5 |
| 責務 | 作成、編集、詳細、一覧が混ざっていないか | 作成/編集はmodal、詳細は行内toggle | 5 |
| 状態変化 | 押した後に何が変わったか分かるか | `/todos/new` で作成modalが出る | 5 |
| クリック範囲 | 見た目と反応範囲が一致しているか | title clickで完了にならない | 5 |
| 入力meta | 必須、任意、文字数、エラーが入力欄の近くにあるか | `タイトル 必須`、`12 / 80文字` | 5 |
| ノイズ | 利用者の作業に不要な情報が出ていないか | `Quality Harness` はUIから消す | 5 |
| 表示の安定性 | 操作で不要に高さや位置が大きく変わらないか | 詳細展開で一覧の見通しが悪くならないか | 4 |
| 失敗時 | API失敗や0件時に次の動きが分かるか | `もう一度試す` を出す | 4 |
| モバイル | 狭い画面でも選択、入力、操作が苦しくないか | 分類チップは横スクロール | 4 |
| a11y | キーボードや読み上げでも意味が通るか | checkboxに `aria-label` を付ける | 4 |
| ハーネス化 | 機械で見られる条件に変換できるか | `詳細ボタンがない` をE2Eで確認 | 5 |

## 3. フィードバックを変換する型

```text
1. ユーザー原文
   - 例: 詳細が右上に出るのはUXとして悪い。

2. 大切にしていること
   - 例: 情報は対象の近くに出す。操作距離を短くする。

3. 問題の種類
   - 例: 配置 / 責務 / 操作距離

4. 変更前
   - 例: 詳細が右上パネルに出る。

5. 変更後
   - 例: 詳細は対象カード内で行内toggle表示する。

6. 最終成果物
   - 例: カード本文クリックで開閉。編集はmodal。右側の詳細ボタンは置かない。

7. 確認方法
   - 例: E2Eでカード本文クリック、再クリック、編集modalを確認する。

8. 次回の再発防止
   - 例: 詳細、編集、作成の表示形式を先に分ける。
```

## 4. 暗黙知として残す単位

暗黙知は、単発の感想ではなく、次に使える小さい型として残す。

| 残す単位 | 書くこと | 例 |
|---|---|---|
| 状況 | いつ、何を見て出た違和感か | TODO一覧の詳細表示 |
| ユーザー原文 | 指摘そのもの | `なんでここに出てくるの？` |
| 観点 | どの見方で問題になったか | 対象との近さ |
| 修正 | 何をどう変えたか | 右上詳細を行内toggleへ変更 |
| 価値 | 何が良くなったか | 対象との関係が分かる |
| ハーネス条件 | 次回機械で見られること | `右側に詳細ボタンがない` |
| 残り | まだ人間確認が必要なこと | 高さ変化が自然か |

## 5. 注意

- すべての観点を毎回全部使わない。重くなるため。
- まず `提供価値 / 対象との近さ / 責務 / 状態変化 / クリック範囲 / ノイズ` を見る。
- そのあと、必要なら `モバイル / a11y / 失敗時 / ハーネス化` を足す。
- 人間の違和感を、いきなりハーネスで直接検出できるものとして扱わない。
- ハーネス化する時は、必ず機械で見られる条件へ変換する。

## 6. 今回のTODO UIでの例

| ユーザー指摘 | 変換後の判断 | 最終形 |
|---|---|---|
| `Quality Harness` はいらない | 利用者UIに内部成果物名は不要 | 画面とtitleから削除 |
| `/todos/new` に行っても変わらない | URL変化と画面変化がズレている | 作成modalを表示 |
| 詳細が右上に出る | 対象との距離が遠い | 対象カード内で行内toggle |
| 詳細/閉じるボタンが違和感 | 操作が重複している | カード本文クリック + `+ / -` 表示 |
| title clickで行が消える | クリック範囲が広すぎる | checkboxだけ完了操作にする |
| 必須/任意が遠い | 入力metaと入力欄の距離が遠い | label横にbadge、欄下に文字数 |
